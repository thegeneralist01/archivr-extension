# Changelog

No public release has been published yet. Version 0.1.4 is the current unpacked development build.

## Unreleased

- Optional browser cookie and localStorage capture from the in-page dialog, with editable values and a settings permission grant. Cookie use defaults on for ordinary sites and off for social sites; localStorage is limited to the current page origin.
- Repository documentation, agent instructions, contributor/security/privacy guides and contribution templates.
- Reproducible CI against a pinned shared frontend revision.
- MIT and third-party notices included in packaged builds.

## 0.1.4 — development build

- Server onboarding, token-based pairing, archive selection and connection recovery.
- Page and selected-text captures with editable title/body and optional manual title generation.
- X Tweet/Thread actions and video capture in native and recognized English custom menus, including dynamic reinsertion and the rounded Archivr mark.
- YouTube video targeting and playlist/channel capture links; one applicable page context-menu action.
- Shared CaptureDialog with media quality and advanced options, fallback capture page and durable job polling.
- Consistent onboarding/settings/popup/capture/notification styling and local fonts.
- Capture notification cleanup for batches/repeated locators; preserved warning details.
- Deterministic production JSX builds and manifest validation.
